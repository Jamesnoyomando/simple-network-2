This lab produced a complete, working enterprise network. A VLSM plan from the 6.20.6.0 block gave each LAN and router link a subnet sized to its hosts. VLANs separated the Administration, ICT/Support, Student Services and Visitors networks, with a trunk and router on a stick on R3. DHCP pools gave clients their addresses automatically, and OSPF in Area 0 allowed the three routers to share routes, so clients in different LANs could communicate. Verification with ping, traceroute and the show commands confirmed that the network behaved as designed.
The lab also covered security and future planning. SSH with local accounts and encrypted secrets replaced Telnet for remote management. An extended ACL on R3 stopped visitors reaching the Administration and ICT/Support networks, while still allowing DHCP, and the show access-lists counters proved the rules were working. An IPv6 dual-stack plan using the documentation prefix 2001:db8::/32 showed how the network could be extended, and the troubleshooting exercises built the skills needed to find and fix faults. Overall, the lab met its objectives and showed how planning, configuration, security and testing fit together in a network design.
